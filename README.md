# Tool OLM 

Tool tự động hóa hỗ trợ tương tác và phân tích API học tập trên nền tảng OLM.vn.

> **Tuyên bố từ chối trách nhiệm :**  
> Dự án này được phát triển hoàn toàn vì mục đích học tập, nghiên cứu kiến trúc API và tối ưu hóa quy trình kỹ thuật cá nhân. Tác giả không chịu trách nhiệm cho bất kỳ hành vi lạm dụng hay vi phạm điều khoản dịch vụ nào từ phía người sử dụng.

## Cài đặt & Sử dụng
- Yêu cầu Python 3.8+ và Node.js.
- Cài đặt thư viện: `pip install requests`
- Chạy tool: `python tool-olm.py`
